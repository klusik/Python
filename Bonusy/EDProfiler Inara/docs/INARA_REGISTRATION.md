# Inara Application Registration

Inara's developer guide states that applications must be identified and the
application name must be whitelisted before public use.

Prepare the following information for Inara:

1. **Exact application name**
   - This must match the value entered in the application's
     **Registered application name** field.
2. **Purpose**
   - Example: "A personal desktop tool that downloads the basic commander profile
     exposed by the official getCommanderProfile API event and saves it locally
     as JSON."
3. **Short description**
   - Example: "Tkinter-based personal Inara profile downloader."
4. **Download or project URL**
   - Supply the repository or release URL when available.

Official developer guide:

https://inara.cz/elite/inara-api-devguide/

Keep **Development mode** enabled while testing. The application defaults to
that mode.
